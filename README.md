# Smart Banking (Demo)

This is a small Flask demo project for educational purposes.

Quick start (local):

```bash
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
flask --app app.py run
```

Basic features:
- User registration and login
- Face image upload
- ATM search API

Notes:
- This project is a demo; do not use in production without hardening.
